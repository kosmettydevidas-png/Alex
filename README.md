# AI Chatbot Documentation

## Overview
This project is an AI chatbot similar to ChatGPT, designed to facilitate user interaction through natural language processing. The chatbot can engage in conversation, answer questions, and provide information on various topics.

## Features
- **Natural Language Understanding**: The chatbot can understand and respond to user inquiries in natural language.
- **Context Awareness**: It retains context over multiple interactions, improving the relevance of responses.
- **Customizable Personality**: Developers can adjust the chatbot's personality and tone to fit specific use cases.
- **Multi-domain Knowledge**: Trained on diverse datasets, allowing it to respond to a wide range of topics.

## Getting Started
### Prerequisites
- Python 3.x
- Required libraries: `transformers`, `torch`, `flask`

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/kosmettydevidas-png/ALEX.git
   ```
2. Navigate to the project directory:
   ```bash
   cd ALEX
   ```
3. Install necessary dependencies:
   ```bash
   pip install -r requirements.txt
   ```

### Usage
To run the chatbot, use the following command:
```bash
python app.py
```
Access the chatbot at `http://localhost:5000`.
